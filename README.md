## 🛠️ Stack Technique

### Backend
- **PHP** (POO + Custom MVC)
- **MySQL**
- REST APIs
- Authentification sécurisée (bcrypt, sessions, RBAC)

### Frontend
- **HTML5** sémantique
- **CSS3** (variables, animations, dark/light mode)
- **Vanilla JavaScript** (sans framework)

### Autres
- SEO avancé (Schema.org, sitemaps dynamiques, Open Graph)
- Sécurité : Protection contre injections SQL, CSRF, XSS, rate limiting
- Déploiement : Vercel, Hostinger
- Outils : Git, VS Code, XAMPP
